# 🌐 Personal Portfolio Website (Source Code)

This repository contains the frontend source code for my personal Data Analyst portfolio website. It is a fully responsive single-page application designed to showcase my projects in Machine Learning, SQL, and Data Analytics.

## 🚀 Live Deployment
The website is currently deployed via GitHub Pages:
### 🔗 [View Live Site](https://mosaizancoder.github.io/My_Portfolio/)

---

## 🛠️ Technology Stack
The portfolio is built using pure frontend technologies to ensure speed and lightweight performance:

* **Structure:** HTML5
* **Styling:** CSS3 (Custom responsive design)
* **Interactivity:** JavaScript (Tab switching, mobile menu, form handling)
* **Icons:** FontAwesome 6.5.2
* **Form Backend:** Google Apps Script (connected to Google Sheets)

---
